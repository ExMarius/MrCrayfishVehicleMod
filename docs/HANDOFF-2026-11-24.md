## Repere de lucru (valabile din orice stare)

* build doar pe GitHub Actions; nimic nu se declară gata până nu trece CI-ul
  și nu se vede în joc
* fără ViaVersion, fără branding MrCrayfish
* ștergerea unui vehicul = doar modelul (`tools/deleted_models.txt`), sistemul rămâne
* comenzi utile: `/vehicle spawn <id>`, `/vehicle creative`, `/vehicle paint`,
  `/vehicle seatglue on`, `/vehicle seatheight -0.85`
* teste: `python3 -m unittest discover -s tools -p 'test_*.py'` + suita Gradle
* unelte: `tools/build_resource_pack.py` (pack), `tools/horizon_import.py`
  (import Horizon), `tools/import_external_pack.py` (import generic 1:1),
  `tools/scratch_models.py` (caroserii desenate de la zero),
  `tools/model_preview.py` (randare offline, nu ține cont de `rotation`)
