## Cum se pornește un branch curat

Sesiunea curentă rulează pe `arena/2f9f7b9e-mrcrayfishvehiclemod` și **nu**
creează/comută alte branch-uri. Pentru un început curat, dintr-o sesiune nouă
sau local:

```bash
git fetch origin
git switch -c curat-2026-11-24 a3c17bc     # sau commit-ul ales din tabel
```

Alternativ, în Arena: sesiune nouă pe branch-ul `arena/...`, iar primul pas este
`git reset --hard <COMMIT>` dacă vrei exact starea respectivă.

## Ce e în lucru / neterminat

* **Roțile Horizon** (`hz_wheel_sports`, `hz_wheel_standard`) sunt în pack dar
  nu sunt tip selectabil; vehiculul `horizon_off_roader` pornește cu roata
  standard. De adăugat ca `WheelType` + default pe spec.
* Al doilea grup al roții Horizon (2 elemente la 67,5°) e eliminat: vanilla nu
  permite unghiul, iar roata ar cere încă un display per roată.
* **Caroseriile proprii** (`tools/scratch_models.py`) sunt funcționale și
  testate, dar dezactivate (`SCRATCH_BODIES` gol) — nu erau mai bune decât r41.
* Restul vehiculelor Horizon se importă cu același pipeline:
  `tools/horizon_import.py` + `tools/external_models/`.
