# External source assets

- `cfm_sofa_single.json` is the original `sofa_single` model from MrCrayfish's Furniture Mod, branch `1.16.X`:
  `src/main/resources/assets/cfm/models/block/sofa_single.json`.

The Sofacopter is explicitly registered as a Furniture Mod-dependent vehicle and references `cfm:red_sofa` in the authoritative Vehicle Mod renderer. The model is included under the repositories' GPL-compatible source terms; the built resource pack includes this repository's `MOD-LICENSE.txt` as `LICENSE.txt`.
